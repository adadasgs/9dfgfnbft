# NFT Profile Radar

Отдельный Telegram-бот для поиска NFT-подарков в профилях известных Telegram-пользователей и публикации результатов в отдельную группу.

## Важно об источнике пользователей

Telegram API позволяет запросить список подарков у конкретного известного пользователя. Это не глобальный поиск по всем аккаунтам Telegram. Укажите `SCAN_SOURCE_CHAT` для группы, участники которой будут проверяться, или перечислите известные аккаунты в `SCAN_USERS`.

Сканер использует MTProto через отдельную пользовательскую авторизацию (`API_ID`, `API_HASH`, `SESSION_STRING`). Не передавайте session string посторонним: он даёт доступ к аккаунту.

## Render

- Build Command: `pip install -r requirements.txt`
- Start Command: `python server.py`

Добавьте переменные из `.env.example` в Render Environment. `DESTINATION_CHAT_ID` — ID новой группы-получателя. Бота нужно добавить в неё администратором с правом отправлять сообщения.

## Текущие ограничения

- Сканируются только аккаунты из `SCAN_SOURCE_CHAT` и/или `SCAN_USERS`.
- Проверяются collectible NFT gifts, доступные через `payments.getSavedStarGifts`.
- Пять диапазонов GRAM сохранены как категории проекта, но цена профиля пока не выставляется: Telegram API не даёт готовую оценку общей стоимости профиля. Не назначаем ценовой диапазон без надёжного источника цены.
- «Написать продавцу» открывает публичный username, если он есть. Бот не рассылает личные сообщения автоматически.

## Первичная проверка

После запуска отправьте боту `/scan` в личном чате, чтобы проверить текущий список источников вручную.
